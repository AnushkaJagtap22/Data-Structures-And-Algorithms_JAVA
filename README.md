# 📘 DSA in Java

This repository contains **Data Structures and Algorithms (DSA)** implementations written in **Java**, organized topic-wise for easy understanding and practice.

It is mainly intended for:
- Learning DSA concepts
- Practicing recursion, backtracking, and core algorithms
- Building strong problem-solving foundations in Java

---
##  🛠 Technologies Used

- **Language:** Java  
- **IDE:** VS Code / IntelliJ IDEA  
- **Compiler:** javac  
- **Java Version:** JDK 8+

---

⚠️ Do **not** use `.java` while running with `java`.

---

## 📚 Topics Covered

- Arrays  
- Recursion (Basics & Advanced)  
- Backtracking  
- Divide and Conquer  
- Bit Manipulation  
- Sorting Algorithms  
- String Algorithms  
- Time & Space Complexity Analysis
